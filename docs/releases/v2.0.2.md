# Kaze 2.0.2

## What's fixed

- Seek forward and backward while online songs are still streaming. Seeking ahead buffers until the requested audio arrives.
- Keep track changes and shutdown responsive when a streaming seek is waiting for audio.
- Show completed downloads as plain icons without a box background or text label, including the player and discovery cards.
- Preserve filling percentage progress below Trending songs artwork while downloading, then switch to the plain completed icon.

## Arch/AUR packaging update (2.0.2-2)

The updated AUR recipe automatically selects stable Rust when the current Cargo
or compiler does not work, installing the minimal toolchain through rustup if
needed. Existing working toolchains are reused. This fixes builds stopping with
“Kaze needs a working Rust toolchain” when rustup is installed without a configured
compiler.

The recipe bundle is available as `kaze-2.0.2-2-aur.tar.gz` below. AUR helper users
receive this fix once revision 2.0.2-2 is published to AUR. This is a packaging
update for Kaze 2.0.2; prebuilt installers do not require Rust.
