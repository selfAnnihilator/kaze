# Kaze 2.0.0

Kaze 2.0 brings local and online music together around one Rust playback engine, with exact recording selection and a more responsive personal library.

## What’s new

- **Integrated JioSaavn music:** search, charts, playlist imports, online playback and selected-song downloads use one source. Songs retain the recording, release and artwork you selected.
- **One player for every song:** local files, streams and cached audio share the queue, playback history and listening statistics. Buffering and stale responses stay scoped to the current song.
- **More personal discovery:** recommendations account for qualified listening time, meaningful repeats, likes, skips, language and artist releases. Refresh For You to explore a different relevant batch when alternatives exist.
- **Simpler Flow and complete search:** Start/Pause Flow resumes the current session, and online search displays every returned song in a virtualized list.
- **Exact-song downloads and feedback:** download the displayed recording directly, track progress in the song control, and exclude or allow songs in recommendations.
- **Library improvements:** play or pause Library Moment from its cover, open the exact album separately, browse complete album contents and use accurate section counts. Album shelves support mouse dragging and long-title clipping.
- **Reliable saved identity:** cloud sync preserves exact source snapshots, supports independently saved legacy/canonical IDs across devices, and honors the online-music setting for playlist imports.
- **Interface fixes:** narrow-window artwork stays within its column, pointer actions keep keyboard shortcuts predictable, and playback progress remains isolated from the main interface.

## Updating

Existing local music, playlists, likes, history and settings are retained. Online music remains optional in Settings; local-file playback stays independent. Metadata filling is reversible and does not rewrite original audio tags.

The production cloud database migration and Worker update are already deployed. If an older cloud backup previously lost a converted song’s recording link, sync from a device that still has the intact selection to recover it.

The `.sig` files and `latest.json` support automatic update verification and do not need to be downloaded manually.
