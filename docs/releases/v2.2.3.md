# Kaze 2.2.3

## Android

- Music Taste lets you pick several song languages and any number of genres. The artist step comes last: it starts with artists who sing in your chosen languages, then suggests similar artists and frequent collaborators as you pick. You can pick up to five. Change your choices any time in Settings.
- For You and Flow start with the languages you chose and add more as you listen to songs in other languages.
- Signing in to an existing account no longer opens Music Taste automatically.
- Top Charts has a feed for each language. Search understands queries like "Malayalam top hits" and shows matching playlists under All and Playlists.
- Library's Playlists tab shows the playlists you created, imported and saved. Liked Songs has its own tab. Tapping Like while signed out tells you that you need to sign in.
- Media controls go away when playback stops or Kaze closes.
- Kaze recovers if its settings briefly fail to load at startup.
- Kaze asks for the permission to reopen after an update only once.

The PC app has no changes in this release.

## Verification

189 Node tests passed. Clippy reports no warnings, and the conventions audit passes. All Rust tests pass except one Flow scoring snapshot test, which also fails on 2.2.2. No database migration.
