# Kaze 2.1.0

## Recommendations

- Recommendations now draw on Last.fm artist similarity, your likes and "not interested" choices for whole artists and albums, and the time of day. Daily mixes, smoother transitions between songs and an auto-explore slot for new music are included.
- Queued tracks show their real titles.

## Downloads

- Kaze's downloads (in `~/Music/Kaze`) are kept apart from your local library. The Downloads tab looks and behaves like Local: search, rescan, play all and shuffle.
- Download state is exact and updates live. Songs you already own show as downloaded in search results, and failed downloads show a short reason inline.
- Removing a download turns the song back into its online version. Its likes and playlist entries stay.
- Files deleted from the folder outside Kaze simply disappear from Downloads.

## Other improvements

- Import Spotify playlist links; the songs are matched on JioSaavn.
- Playback recovers when an audio device appears after Kaze has started.
- The database tolerates profiles from newer versions and backs up the profile before migrating.
- Library lists no longer jump or flash "Loading music…" when they refresh, and the action buttons no longer crowd the duration.
- Lyrics are virtualized, and bundled images and fonts are smaller.
- Library scan failures are reported instead of failing silently.
- Colors, fonts, sizes, spacing, corners, layers and motion now come from one token file (`src/styles/tokens.css`), so colors that were hardcoded now follow the Spatial and Brutalist themes. Some sizes and spacings moved by 1–2px.

## Upgrading

This release adds four database migrations (artist similarity, entity feedback, audio features and exploration slots). They run automatically, after a backup of the profile. A profile opened by 2.1.0 cannot be opened by 2.0.5 or earlier.

## Verification

373 Rust tests (14 ignored), 87 Node tests, 30 browser checks across both interfaces, clippy over all targets, the frontend production build, a native build and the conventions audit all passed locally. The internal file-size refactors in this release do not change behaviour.

## Known limitations

The earlier suspend-related hang and long-session memory growth remain unproven/unresolved. Windows and macOS runtime acceptance has not been tested.
