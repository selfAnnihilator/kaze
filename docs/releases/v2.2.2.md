# Kaze 2.2.2

## Android

- Kaze can now reopen itself after an update. Before your first in-app update, Kaze opens Android's "Display over other apps" page once: allow Kaze there, and from then on it starts again on its own when an update finishes. Without it, reopen Kaze yourself as before. Android only lets apps with this setting open themselves.
- The startup screen stays for 3 seconds instead of flashing past.

The PC app has no changes in this release.

## Verification

173 Node tests passed, with Android clippy and the conventions audit clean. Tested on an Android 14 phone: an in-app update installed and Kaze reopened by itself three seconds later. No database migration.
