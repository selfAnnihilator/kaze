# Kaze 2.2.4

## Android

- When you're signed out, a Settings gear now sits in the top bar, left of the profile icon. Before, Settings could only be reached from Profile, which needs you to be signed in.
- Music Taste no longer limits how many artists you can pick.

The PC app has no changes in this release.

## Verification

189 Node tests passed, plus the Music Taste Rust tests, including a new one that saves eight artists. Clippy reports no warnings, and the conventions audit passes. Tested on an Android 14 phone: signed out, the gear appears and opens Settings, and the artist step accepted a sixth artist. No database migration.
