- `node scripts/test-five-defects.mjs` — actual App in Spatial and Brutalist, isolated fixture profiles. Set `KAZE_EVIDENCE_DIR` to an existing directory with a trailing slash to retain JSON/screenshots.

- `CARGO_BUILD_JOBS=1 cargo +1.98.1 test --offline --locked --manifest-path src-tauri/Cargo.toml --test playback_restore_tests` — three additional zero-duration tests alongside existing restoration cases.
- `KAZE_PRIVATE_DEFECT_TEST=1 dbus-run-session -- python3 scripts/test-duration-native.py` — copies the embedded debug binary, creates synthetic WAVs and disposable XDG profiles, and starts its own private Xvfb display. Set `KAZE_EVIDENCE_DIR` for retained native evidence.

## Limits

Native execution uses GTK X11 on a private virtual display, synthetic WAVs and controlled metadata, not a live provider or ordinary importer zero-duration case. The before-native artifacts are preserved observations from the supplied earlier review, not new native pre-fix runs in this task. There is no claim to resolve suspend/resume shutdown or memory growth, run a long Wayland memory test, publish a release, or alter the running personal session. The development StrictMode browser mounts produce one abandoned registration attempt plus four attempts for the live owner; deterministic owner backoff checks verify exactly four. Full interactive cloud authentication is outside these fixture checks; its separate Rust auth test remains opt-in.
